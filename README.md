# Learning-Python-InDepth
Diese Repository werde Ich nutzen, um nochmal die Programmiersprache Python zu wiederholen. Ich werde danach weitere Projekte in Richtung von Maschinellen Lernen und Datenverarbeitung mit Python probieren und kreieren.

## calculator.py
Ich habe zuerste einen simplen Kalkulator gecoded, der bisher nur die basic Operatoren [+, -, *, /] ausführen kann in Float Zahlen.

## guessing_game.py
Ich habe ein simple Idee umgesetzt, bei der man eine Zahl erraten muss, dessen Range man sich selber aussuchen kann.

## secretword.py
Ein simples Wort erraten Spiel, ähnlich wie Galgenmänchen. Man hat 12 Versuche um ein Wort zu erraten. Bis jetzt sind die Wörter selber angelegt.

## translator.py
Ein simples Programm, dass einen Satz in eine geheime Sprache umstellt. Statt den Vokalen, wird ein G/g eingesetzt

## sound.py
Ein simples Programm zum testen, wie man Audio aufnimmt.
